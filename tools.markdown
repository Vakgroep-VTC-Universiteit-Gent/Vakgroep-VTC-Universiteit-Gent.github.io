## Corpus consultation

| Tool | Description | Target languages | Owners | Access |
| --- | --- | --- | --- | --- |
| [CorpusMate](https://corpusmate.com/) | CorpusMate aims to provide a streamlined, simplified language data analysis experience for (younger) learners of English. The most distinctive feature of the tool is that it collapses the keyword-in-context (KWIC) results into one single line per pattern, which considerably increases the "digestibility" of the corpus query. For more details, we refer to the corresponding [paper](https://www.jbe-platform.com/content/journals/10.1075/ijcl.23056.cro). | English | Peter Crosthwaite (University of Queensland) and Vít Baisa | Free |
| [SCAP](https://scap.ugent.be) | The "Consultar" section of the SCAP (Spanish Corpus Annotation Project) platform allows users to (1) analyse how (sequences) of words are used in a series of Spanish corpora and (2) create word lists for these corpora. | Spanish | Patrick Goethals (Ghent University) | Free* |
| [SKELL](https://www.sketchengine.eu/skell/) | SKELL (SKetch Engine for Language Learning) enables language students and teachers to check the usage, collocations, and synonyms of a particular phrase or a word is used in authentic data. All examples, collocations, and synonyms were identified automatically by computational algorithms and state-of-the-art software analysing large multi-billion samples of text. | Czech, English, Estonian, German, Italian, Russian | Sketch Engine | Free |

## Generative artificial intelligence (GenAI)

**IMPORTANT**: Ghent University recommends Microsoft Copilot as the go-to GenAI tool, since data protection is - unlike with other tools such as ChatGPT - guaranteed thanks to an agreement with Microsoft.

| Tool | Description | Target languages | Owner | Access | Recommendation |
| --- | --- | --- | --- | --- | --- |
| [ChatGPT](https://chatgpt.com/) | ChatGPT is an AI assistant that uses deep learning to generate human-like text based on so-called "prompts". It works by predicting the next word in a given text, based on the patterns it has learned from a massive amount of data during its training process. Apart from generating text, it is also able to generate programming code and create images. With the "web search" functionality enabled, ChatGPT will search the web for pages that are related to your prompt and take into account this information when generating its response. For a more elaborate description, we refer to the [OpenAI article](https://help.openai.com/en/articles/6783457-what-is-chatgpt) and [overview page](https://chatgpt.com/overview/) on ChatGPT. | For the full list of languages, we refer to the corresponding [OpenAI article](https://help.openai.com/en/articles/8357869-how-to-change-your-language-setting-in-chatgpt). | [OpenAI](https://openai.com/about/) | Free** | ChatGPT can be used as an "idea provider", writing **assistant**, programming companion, or analyst. Using ChatGPT as a search engine (especially if the web search functionality is disabled) or translator should be done with caution, as the tool is not specifically designed to stick to factual information (i.e. it can "hallucinate"). |
| [Claude](https://claude.ai/) | Like ChatGPT, Claude is an AI assistant that uses deep learning to generate human-like text based on so-called prompts (see the ChatGPT entry for the full description). Although it offers support for a wide variety of tasks, Claude has been especially acclaimed for its programming capabilities. Another aspect that distinguishes Claude from other AI assistance is ["Constitutional AI" foundation](https://www.anthropic.com/news/claudes-constitution). In brief, this principle provides Claude's language models with explicit values determined by a constitution, rather than with values determined implicitly via human feedback. | Best results will be obtained for English, although languages such as Spanish, French, German, Italian, Portuguese, Dutch, Russian, Chinese (Mandarin), Japanese, Korean, Arabic, and Hindi are also supported. | [Anthropic](https://www.anthropic.com/company) | Free** | Claude can be used as an "idea provider", writing **assistant**, programming companion, or analyst. Using Claude as a search engine (especially if the web search functionality is disabled) or translator should be done with caution, as the tool is not specifically designed to stick to factual information (i.e. it can "hallucinate"). |
| [Vibe](https://chat.mistral.ai/chat) | Like ChatGPT, Vibe (formerly Le Chat) is an AI assistant that uses deep learning to generate human-like text based on so-called prompts (see the ChatGPT entry for the full description). By open sourcing (some of) their models, Mistral AI (i.e. the company behind Vibe) aims to make AI accessible to all. Thanks to its French roots, GDPR-compliant data processing is ensured when using Vibe. For a more elaborate description, we refer to the [Mistral AI web page on Vibe](https://mistral.ai/products/vibe/). | Best results will be obtained for English, Dutch, German, French, Spanish, Italian, Portuguese, Russian, Chinese, Japanese, and Arabic. | [Mistral AI](https://mistral.ai/about) | Free** | Vibe can be used as an "idea provider", writing **assistant**, programming companion, or analyst. Using Vibe as a search engine (especially if the web search functionality is disabled) or translator should be done with caution, as the tool is not specifically designed to stick to factual information (i.e. it can "hallucinate"). |
| [Lumo](https://proton.me/lumo) | Like ChatGPT, Lumo is an AI assistant that uses deep learning to generate human-like text based on so-called prompts (see the ChatGPT entry for the full description). Unlike most of the (commercial) AI assistants, however, Lumo does not "harvest" data entered by the user. Thanks to zero-access encryption, chat conversations can only be decoded and read on your device. Lumo can never see them, and neither can anyone else. For a more elaborate description of the tool, we refer to Lumo's [home page](https://proton.me/lumo). | Best results will be obtained for English, French, German, Spanish, and Italian. Support for more languages might be added in the future. | [Proton](https://proton.me/about) | Free** | Lumo can be used as an "idea provider", writing **assistant**, programming companion, or analyst. Using Lumo as a search engine (especially if the web search functionality is disabled) or translator should be done with caution, as the tool is not specifically designed to stick to factual information (i.e. it can "hallucinate"). |
| [NotebookLM](https://notebooklm.google/) | Developed by Google and powered by the Gemini chatbot, NotebookLM is a tool that can be used to summarise documents uploaded by the user, answer questions about them, or even transform them into reports, study guides, or podcasts. | For the full list of languages, we refer to the corresponding [NotebookLM Help article](https://support.google.com/notebooklm/answer/16261963?hl=en&co=GENIE.Platform%3DDesktop#zippy=%2Csupported-languages-in-browser). | Google | Free** | As NotebookLM is specifically designed to base its output on the documents provided by the user, it is less likely to hallucinate than general-purpose GenAI chatbots. Importantly, although Google claims that "NotebookLM does not use your personal data, including your source uploads, queries, and the responses from the model for training", data protection is not guaranteed (as mentioned above, Ghent University's recommendation is to use Microsoft Copilot). |

## Literature review

| Tool | Description | Target languages | Owner | Access | Recommendation |
| --- | --- | --- | --- | --- | --- |
| [Elicit](https://elicit.com/) | Elicit is an AI assistant specialised in analysing research papers. It aims to (partially) automate time-consuming research tasks such as synthesising research findings and generating a literature overview. | English | [Elicit](https://elicit.com/team) | Free** | Elicit can be used to **help** find related research for a given research question and write a summary of that related research. Important to note, however, is that the tool can only access open-access sources (unless a paywall-protected paper has also been published as a preprint or the paper is in the company's database). Moreover, Elicit should also not be used as a bibliographical library; for this purpose we highly recommend using a tool such as [Zotero](https://www.zotero.org/), which allows storing bibliographical references into different collections and exporting these collections to the right format (e.g., MLA, APA, or BibTeX). Best of both worlds can be combined by [connecting Elicit with Zotero](https://support.elicit.com/en/articles/14744239-import-papers-from-zotero). |
| [SciSpace](https://scispace.com/) | SciSpace is an AI assistant specialised in analysing research papers. It aims to (partially) automate time-consuming research tasks such as synthesising research findings and generating a literature overview. | For the full list of supported languages, we refer to the corresponding [SciSpace help article](https://scispace.com/help/en/articles/14686421-how-to-change-the-language-in-scispace). | [SciSpace](https://scispace.com/t/about/) | Free** | SciSpace can be used to **help** find related research for a given research question and write a summary of that related research. Best of both worlds can be combined by [connecting SciSpace with Zotero](https://scispace.com/help/en/articles/10719251-how-to-connect-scispace-with-zotero). |
| [Sciwand](https://sciwand.com/) | Sciwand is a search engine with AI capabilities specialised in analysing research papers. It allows users to search various academic databases such as PubMed and Google Scholar, interrogate hundreds of PDFs, and write drafts in which all claims trace back to real sentences from the sources analysed. Importantly, Sciwand lets you use your GenAI model of choice for analysing the sources, including open-source models that can be run locally (meaning that you can make sure your data never leaves your device, which can be important for ethics and/or copyright requirements). | English, though a [how-to guide](https://sciwand.com/blog/how-to-auto-extract-key-findings-from-translated-non-english-literature-in-your-reference-library) is provided on how to use the tool for analysing non-English texts | Sciwand | Programme without AI features is free, programme with AI features has to be purchased via a licence (one-time payment, lifetime updates) | Sciwand can be used to **help** find related research for a given research question and write a summary of that related research. Important to note, however, is that the tool can only access open-access sources (unless a paywall-protected paper has also been published as a preprint).
